# Overview Beasiswa Matahari v1

## Tujuan Proyek

Website Beasiswa Matahari v1 berfungsi sebagai pusat informasi publik untuk:

- memperkenalkan profil Beasiswa Matahari,
- menampilkan alur pendaftaran beswan,
- menjelaskan program donasi,
- menyediakan FAQ untuk calon beswan dan donatur,
- menampilkan pencapaian dan testimoni.

## Stack

- Static HTML pages.
- CSS utama di `assets/css/main.css`.
- JavaScript bawaan template HTML5 UP di `assets/js/`.

## Karakter Visual

Desain diarahkan ke tampilan yang:

- lebih rapi,
- hangat dan ramah,
- mudah dibaca di desktop maupun mobile,
- konsisten antar halaman.

## Struktur Halaman

- `index.html` - landing page utama.
- `formulir.html` - akses ke formulir pendaftaran.
- `pengurus.html` - roster pengurus dan alumni pendukung program.
- `pencapaian.html` - ringkasan penyaluran dana dan laporan.
- `testimoni.html` - kutipan dukungan dari dosen.
- `donatur-faq.html` - FAQ untuk donatur.
- `beswan-faq.html` - FAQ untuk beswan.

## Prinsip Pemeliharaan

1. Perubahan visual utama dimulai dari stylesheet global.
2. Konten halaman dijaga tetap ringkas dan mudah dipindai.
3. Link internal dan eksternal harus tetap aktif setelah revisi.
